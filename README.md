# Условное форматирование списка/журнал документов
В бухгалтерском учете особое внимание уделяется договорам в иностранной валюте, условных единицах.
<br>Почему? Потому что при закрытии месяца рассчитываются курсовые разницы. 
<br> Чтобы подсветить такие операции, выделим Приобретения по таким договорам сиреневой заливкой
